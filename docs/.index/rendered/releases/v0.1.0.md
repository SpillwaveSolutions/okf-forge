# Release v0.1.0

`release/v0.1.0` · **shipped**

11 item(s) shipped.

## Change Log

- [[Ticket-01KYZ24K4MKBE0VN4YAZ84V221]] Nested collapsible file tree in the sidebar — The sidebar grouped concepts by their first path segment only, so a bundle with agents/foo/bar.md collapsed every nested file under a single 'agents' heading.
- [[Ticket-01KYZ24K90F9SS04CRSJRB65R4]] Filesystem walkers pull in build output and flatten upload paths — Opening a real repository pulled build output into the bundle: the three filesystem walkers (Rust desktop, Node dev-server, browser upload) each had their own idea of what to skip, and only skipped dotfiles.
- [[Ticket-01KYZ27EFFB9MG32Y3YVFHRTND]] Scaffold worklog and write the project agent guide — The repo was exported from a Grok sandbox with no work tracking, no CI, and an AGENTS.md that was Grok sandbox boilerplate rather than project documentation.
- [[Ticket-01KYZ8TZY5GARKJKNC5NC1PE75]] Lint gate is unlandable: ignore holes plus prefer-const errors — eslint reports errors that CI will never see: the ignore list omits src-tauri/target, so on any machine that has run cargo build, eslint lints generated Tauri build scripts.
- [[Ticket-01KYZ8V02N7W42QKDHYFK9ZS70]] Application quality gate on every pull request — CI runs only the worklog ledger invariants, so a type error, a lint failure, a broken build, or a failing test merges to main unopposed.
- [[Ticket-01KYZ97ESCXSAG4KFAESST84QT]] UI spec, wireframe and layout rubric for the Editor view — Nothing verifies that the app shell actually lays out correctly.
- [[Ticket-01KYZ9TRM50FCMFFZDVW2VZ2CC]] End-to-end tests interact with the app before it hydrates — Three end-to-end tests failed on main and had presumably never passed: the repository was exported from a sandbox where the browser suite was not run in this configuration.
- [[Ticket-01KYZF04XQY6T771RDTCZQRWSY]] Dev server port collides with other projects on the same machine — Several desktop projects are developed side by side on one machine, often by different agents at once, and every Vite template ships the same hardcoded dev-server port.
- [[Ticket-01KYZN9KRDZ0CR758BA3XEJP6C]] Repository has a Prettier config but was never formatted — The repository ships a Prettier config but was never formatted with it: around 29 source files fail a check at any print width.
- [[Ticket-01KYZN9KX5FBTAMYCB2ZP4CSSY]] Desktop storage provider has no JavaScript test coverage — The desktop storage provider has no automated coverage in any tier.
- [[Ticket-01KYZN9M26QS2EATG15KEZYMZ0]] Desktop app cannot be driven by automation — Verifying the desktop application means launching it and looking at it by hand.
